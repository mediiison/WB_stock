# WB Stock Signal

Скрипт формирует отчёт по остаткам на Wildberries и выставляет сигнал по каждому артикулу: когда нужно отгружать товар.

## Как работает

1. Через Statistics API берёт текущие остатки по складам (`/supplier/stocks`).
2. Берёт продажи за последние N дней (`/supplier/sales`), отменённые исключает.
3. Считает среднюю скорость продаж в день и запас в днях (`остаток / продажи в день`).
4. Присваивает статус:

| Статус | Условие (по умолчанию) |
|---|---|
| Грузить срочно | запас ≤ 7 дней |
| Готовить поставку | запас ≤ 14 дней |
| Норма | запас больше 14 дней |

Артикулы без продаж за период получают запас 999 дней (статус «Норма»).

5. Сохраняет результат в Excel, отсортированный от самых срочных.

## Установка

```bash
pip install pandas requests openpyxl
```

## Запуск

Токены передаются через переменные окружения (токен WB с доступом к категории «Статистика»):

```bash
export WB_TOKEN_1="..."
export WB_TOKEN_2="..."   # необязательно, второй кабинет
python wb_stock_signal.py
```

Параметры:

```bash
python wb_stock_signal.py --days 14 --urgent 7 --prepare 14 --out report.xlsx
```

| Параметр | Описание | По умолчанию |
|---|---|---|
| `--days` | окно продаж в днях | 14 |
| `--urgent` | порог для «Грузить срочно» (дни запаса) | 7 |
| `--prepare` | порог для «Готовить поставку» (дни запаса) | 14 |
| `--out` | имя выходного файла | `wb_stock_signal_<дата>.xlsx` |

## Исключённые склады

Список складов, которые нужно игнорировать (например, повреждённые), задаётся в начале скрипта в `EXCLUDED_WAREHOUSES`:

```python
EXCLUDED_WAREHOUSES = {"Название склада 1", "Название склада 2"}
```

Названия должны совпадать с `warehouseName` из API.

## Колонки отчёта

`cabinet`, `supplierArticle`, `nmId`, `stock`, `in_way_to`, `in_way_from`, `sold`, `per_day`, `days_left`, `signal`

## Ограничения

- Statistics API лимитирует запросы (около 1 в минуту на метод), поэтому между запросами стоят паузы, а на 429 скрипт ждёт и повторяет. Полный прогон по двум кабинетам занимает несколько минут.
- Данные Statistics API обновляются не мгновенно, остатки могут отставать от личного кабинета.
